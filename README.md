# ✅ Привычки

**Трекер привычек с сериями и тепловой картой.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/habit-tracker/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Отметка привычек за сегодня и любой день недели
- Серии, лучший результат и процент выполнения за месяц
- Тепловая карта за 26 недель — по всем или по одной привычке
- Свои иконки и цвета, редактирование и удаление
- Светлая и тёмная тема, демо-данные при первом запуске

## Стек

JavaScript, CSS Grid, color-mix(), localStorage. Без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/habit-tracker.git
cd habit-tracker
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
